# Numerologie App

Moderní česká webová aplikace pro západní numerologickou mřížku 3×3 a numerologické výpočty. Inspirováno tématy knih Robin Stein; konkrétní postupy nejsou vydávány za autentická pravidla Stein, pokud nejsou ověřené primárním zdrojem.

## Zadání pro Codex

Začni souborem [`CODEX_TASK.md`](./CODEX_TASK.md), řiď se [`AGENTS.md`](./AGENTS.md) a metodikou v [`docs/METHODOLOGY.md`](./docs/METHODOLOGY.md). Kontrolní případy jsou v [`docs/ACCEPTANCE_TESTS.md`](./docs/ACCEPTANCE_TESTS.md).

## Technologie

React, TypeScript, Vite, Tailwind CSS, Vitest, bez backendu a placených API. Připraveno pro Cloudflare Pages.

## Stav

Tento balíček obsahuje **zadání a metodiku**, ne hotovou aplikaci. Implementaci má vytvořit Codex.

## Soukromí

Osobní datum narození a čas nesmějí být automaticky odesílány na externí server ani ukládány bez vědomé volby uživatele.
